## 2. Different artefacts, different obligations (assuming CC BY-SA applies to the text)
| Artefact | Obligation / risk | Note |
|---|---|---|
| **Source text** (Simple Wikipedia articles) | Attribution (credit authors, link to licence, indicate changes) and ShareAlike for adaptations | Attribution is usually satisfied by linking to the article/history; our pool records `source_url` and `attribution` per passage |
| **Selected excerpts** (passage pool, spans with context) | Still copies of CC BY-SA text, so the same terms follow them into any file that contains them | Short quotations may fall under a legal exception (e.g. fair dealing/fair use, jurisdiction-specific); do not rely on that without advice |
| **Annotations** (your labels, rationales, confidence) | Your annotators' own contribution; whether a file combining labels *and* excerpt text must be SA is the debated point | Safe design: a *combined* file (text + labels) released under CC BY-SA; a *labels-only* file (span_id/offsets + label, no text) plus a rebuild script, under a licence you choose. Annotators need a written consent/contribution statement so you can license their labels (links to HG-02 ethics) |
| **Metadata** (page_id, title, URL, dates) | Facts/identifiers; low obligation, but keep them for attribution | |
| **Model artefacts** (classifier weights) | Unsettled in law whether weights trained on SA text are "adaptations"; practice varies | Conservative: release weights with a model card crediting the source corpus and licence; state the uncertainty; DistilBERT's own licence (Apache-2.0 per Hub metadata) requires its notice |

## 3. Feasible alternatives (licence facts below are from general knowledge unless marked; verify per document)
| Option | Licence burden | Strengths | Weaknesses |
|---|---|---|---|
| A. Simple English Wikipedia (this ADR) | Attribution + ShareAlike | Free, large, traceable authorship, already in the pipeline | Text is *already simplified*, so few hard spans; SA obliges open release of combined data |
| B. English Wikipedia (main) | Attribution + ShareAlike | Harder, more varied text | Same SA burden; no verified Hub copy checked yet; large |
| C. Public-domain text (e.g. Project Gutenberg works; US federal-government pages) | None for the text itself (check each item for third-party content and project-name terms) | No SA; free to relicense combined data | Archaic style (Gutenberg) or narrow domain (government) — poor match to student reading |
| D. CC BY open textbooks (e.g. OpenStax titles, usually CC BY 4.0 — verify per book) | Attribution only | Realistic study material; mixes well with the "CONCEPTUAL" label | Per-book licence checks; some embedded third-party items excluded |
| E. Original or commissioned passages (written by the project/volunteers) | You own them | Full control, any licence | Costs time/people; risk of artificial style |

## 4. Recommendation (provisional; owner decides)
1. Keep ADR-009 PENDING. Do not build `DATA/source_pool.csv` for annotation until you decide.
2. If you want an open academic dataset: A is acceptable *if* you accept releasing the combined data under CC BY-SA, but add D (CC BY textbooks) for harder spans, because A alone will under-represent difficult text. The schema already has a per-row `source_license`, so mixed sources are supported.
3. If you need a permissive or closed release: choose C/D/E instead of A/B.
4. Either way: release labels-only separately from text where possible, get annotator consent in writing, and have your institution confirm before publishing.
