# Windows quick start

1. Install 64-bit Python 3.12 and extract this project into a writable folder.
2. Double-click `START_WINDOWS.bat`. It checks the current multilingual models and runs `SETUP_RESEARCH_WINDOWS.bat` if setup is incomplete. First setup downloads several GB and may take a while.
3. Keep the terminal open. Use `http://127.0.0.1:8000` for the reader and `http://127.0.0.1:8000/learner-lab.html` for the Research Lab.

For manual setup and native Tesseract OCR, see `RUN_RESEARCH.md`. The older `RUN_NEURAL.md` and `/learning.html` describe a legacy prototype.

To use **Help me understand**, select a word or sentence in the reading text, choose a help type, then click the button. The first local response can take time while the model loads. Read aloud uses the installed offline voice; if the browser blocks delayed playback, press Play in the audio controls that appear.

The Research Lab shows only consented, recorded learner activity. Without a saved profile and reading session, its evidence panels are intentionally empty. The local explanation model is integrated, but the three-category human-reviewed routing model and student effectiveness study are not complete.
