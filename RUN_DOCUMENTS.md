# DyslexiAdapt: documents, pictures and actual model evidence

This extends the real-model build. It is a functional local research prototype, not a clinically or educationally validated product.

## Windows: start the updated project

1. Extract this ZIP into a NEW folder. Do not run the older extracted copy.
2. Install Python 3.12 (64-bit) with Add Python to PATH enabled.
3. Double-click START_WINDOWS.bat. Keep its terminal open.
4. First setup installs dependencies and downloads about 4.31 GB of pinned model assets, including the text models and multimodal vision model. Leave enough disk space for dependencies and model files. A 16 GB RAM computer is recommended for concurrent text and vision use. CPU vision may take several minutes.
5. Open http://127.0.0.1:8000 for the student reader; http://127.0.0.1:8000/research.html for evidence; http://127.0.0.1:8000/learning.html for reviewed retraining.

If you already downloaded the earlier text models, you may copy the MODELS/minilm, MODELS/qwen and MODELS/nli folders from the old extracted project into this one. Setup verifies their hashes before reusing them. Never overwrite the new manifests or source files with older ones.

Subsequent starts can skip installation:

```powershell
.\.venv\Scripts\python.exe -m uvicorn BACKEND.app:app --host 127.0.0.1 --port 8000
```

Manual first setup:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r BACKEND\requirements.txt
.\.venv\Scripts\python.exe -m pip install --prefer-binary --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu -r BACKEND\requirements-neural.txt
.\.venv\Scripts\python.exe -m pip install -r BACKEND\requirements-documents.txt
.\.venv\Scripts\python.exe -m ML.model_setup
.\.venv\Scripts\python.exe -m ML.document_setup
.\.venv\Scripts\python.exe -m uvicorn BACKEND.app:app --host 127.0.0.1 --port 8000
```

## Student: upload rather than repeatedly paste

- The upload button is visible on the reading-room screen.
- Supported files: PDF, TXT, PNG, JPG/JPEG, WEBP, up to 25 MB. PDFs up to 500 pages. One selected page is processed at a time.
- Embedded PDF text is extracted directly. Scanned pages and photos use verified Tesseract language weights when installed, or RapidOCR ONNX as a fallback. Read page with OCR again can override a broken PDF text layer. For an English slide, select English as Document language and rerun OCR if automatic detection is wrong.
- The original page stays visible. Check and correct the editable extracted words, then choose Read this text. Read aloud, word/sentence/concept help, notebook, comfort settings and optional profiles continue to work.
- OCR line scores are model scores, not calibrated correctness probabilities. Multi-column order, equations, superscripts, Greek letters, handwriting and tiny labels can be wrong. Correct mathematical notation in the text box before reading aloud or asking for text support. An image without readable words still supports visual questions.
- For a picture-only page, an empty OCR box is expected: OCR reads words, not the shapes or graph. Choose **General picture**, **Biology diagram**, **Physics or other graph**, or **Shapes and geometry** near the top, then click **Explain whole picture**. The answer appears below the picture controls. For small labels, drag a region or use the Left/Top/Width/Height percentage inputs and click **Explain selected picture**. Only the selected crop is sent to the local model.
- Visual answers are generated by Qwen2.5-VL-3B Q4_K_M plus its Q8_0 image projector. The model sees pixels, not just OCR text. Inference uses an image up to 640 pixels per side for CPU practicality; crop closer to small labels. Original preview resolution is preserved.
- Listen to a visual explanation or save it to the notebook. **Read explanation aloud** defaults to the fast browser voice and shows playback status beside the button. If your browser has no working voice for the selected language, it reports that error instead of silently waiting for local synthesis; choose **Local voice (slower)** explicitly to generate an audio player beside the explanation. On this Windows CPU, one short local speech test took about 81 seconds, so local voice is not instant. The picture explanation itself runs through Qwen on the CPU and can also take a minute or more; the page shows elapsed time while it works.
- Visual explanations are unverified; compare the answer with the source image. Exact graph values, biology labels and inferred 3D shapes are not guaranteed. The local model mislabeled the axes on an included chart during manual testing, so default English graph summaries withhold explicit axis claims; check printed axes yourself. If the model is missing or cannot read the image, the app reports an error rather than inventing an answer.
- Optional Remember which support helps me applies to both text and visual styles. Two positive-net feedback observations can guide subsequent automatic styles. Visual feedback does not become text-classifier training data or automatically fine-tune vision weights.

## Admin: evidence and evaluated changes

The overview reads the actual prototype registry and shows recorded model-version validation macro-F1, label counts, per-class validation F1, a validation confusion matrix, real component availability, and opt-in feedback counts. Tables accompany charts and show the same values without relying on colour or hover.

These are version comparisons, not invented epoch curves. The historical human-data research registry remains separately labelled and empty until real research-valid runs exist. JSON and research-note exports include the active prototype evidence. Train & adapt contains reviews, evaluated candidate training, activation gates and rollback. Dataset disagreements remain unresolved with both GPT labels and reasons.

There are still 140 synthetic examples labelled by two GPT passes: 95 agreed, 45 unresolved. Agreed split: 60 TRAIN / 19 VALIDATION / 16 TEST. No new human-annotated dyslexia dataset is claimed. The classifier remains a small weak-label prototype. Feedback collection is not evidence of student benefit.

## Data handling and access

Files are processed locally. Multipart parsing can use transient framework temporary files; they are closed before extraction. Raw uploads, rendered pages and image crops are not retained by the app after processing. Extracted text and images stay in the current browser workspace unless you explicitly save text/notes. Reloading loses the original upload; re-upload to resume page navigation.

Opt-in text passages, visual questions/answers and feedback are stored in the local SQLite profile database. Raw image pixels are not stored there. Forget my support history deletes text and visual feedback. Saved notebook entries and passages have their own browser deletion controls. Existing trained weights do not automatically unlearn reviewed data.

Admin APIs are restricted to loopback by default or require DYSLEXIADAPT_ADMIN_TOKEN when configured. Learner capability keys are not account authentication. Keep the default 127.0.0.1 binding for local use.

## Licenses and boundaries

Built with Qwen. Vision model: original Qwen2.5-VL-3B-Instruct uses the Qwen RESEARCH LICENSE, allowing non-commercial research/evaluation. Its quantized repository card declares Apache-2.0, but this build preserves the original model license and treats the original restriction as controlling. See MODELS/VISION_LICENSE.txt, MODELS/VISION_NOTICE.txt and the pinned vision-manifest.json. A separate commercial license would be needed for commercial use. Text Qwen1.5B, MiniLM and NLI retain their existing licenses and provenance.

OCR prefers installed native Tesseract with verified tessdata_best weights and falls back to rapidocr-onnxruntime 1.4.4 with bundled ONNX assets; PDF rendering uses PDFium through pypdfium2. Installed packages carry their upstream notices. The ZIP distributes source/manifests and synthetic fixtures, not downloaded pretrained weights. Uploaded textbook permissions are separate from model licenses.

No student study, accessibility certification or perfect-answer claim is made. The app does not diagnose dyslexia. The Windows launcher is prepared and its package wheels are checked, but execution validation was on Linux CPU and Chromium, not a native Windows host.
