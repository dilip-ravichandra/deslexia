LOCAL TRAINING WORKSPACE

Advanced: human-data research training

For the active prototype, use Train & adapt to review feedback, train and activate an evaluated candidate. This advanced form prepares terminal commands for a separate human-reviewed research dataset.

Your run checklist

  1. Use approved source material and independently reviewed labels.
  2. Validate the CSV. A filename alone does not make it gold data.
  3. Freeze document-based train, validation and test partitions once.
  4. Run training locally. Existing data/model validation guards stay active.
  5. Compare validation performance before selecting a candidate.
  6. Refresh this page to inspect the saved run. Final test data must stay separate.

If a frozen manifest already exists, skip its creation command and use the existing matching manifest. For a genuinely new dataset version, use a new manifest path and new output version.

CONTROLLED IMPROVEMENT

Learn from feedback, with a review step

1Feedback

A learner says which support was useful. Collection needs informed permission; persistent logs are off by default.

2Human review

Check the selected text, context, licence and support label. Acceptance is not proof that the answer or label is correct.

3New training version

Train a candidate on approved data. Keep provenance, document groups and versions. User activity never directly changes the active weights.

4Evaluate & release

Compare the candidate on validation data. Use separate final evaluation, then deliberately register the chosen model. Keep the previous version for rollback.

Evaluated prototype retraining is available in Train & adapt. A perfect answer is not guaranteed. The category classifier chooses a kind of help; improving definitions or explanations is a separate intervention task.

What can adapt immediately?

Reading colours, font, spacing and saved notes already follow the learner's choices. Opt-in profiles also use helpfulness feedback to recommend a support style next time. This changes routing preferences, not classifier weights.

What must wait for reviewed data?

Classifier fine-tuning, model promotion and claims that support improves understanding. A validated learner study also needs the appropriate approval and consent.

Keep the final test set protected

Use validation data for model selection. Repeatedly choosing improvements based on final test scores contaminates the evaluation. Feedback samples overlapping held-out documents need exclusion or a new independent evaluation design.
