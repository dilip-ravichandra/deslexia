# 00_PROJECT_AUDIT.md

## Objective
Audit repository, environment, existing code and requirements. Produce an architecture map and implementation gap list. Preserve working code.

## Execution contract
1. Inspect current repository.
2. Implement the objective.
3. Add/update tests.
4. Run tests.
5. Save reproducible artifacts.
6. Update PROJECT_STATE.json.
7. Write a task report.
8. Continue to the next unblocked task.

## Guard
Never fabricate scientific evidence.
